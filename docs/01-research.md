# 红楼梦3D动作游戏 - 调研文档

## 游戏概念

**核心定位：** 中国古典文学题材的3D第三人称动作游戏，结合红楼梦的人物、场景与古典武侠战斗。

**视角：** 第三人称俯视角（类似《雾锁山门》）

**题材融合：**
- 红楼梦的大观园场景和金陵十二钗角色
- 武侠风格的战斗系统
- 中国传统美学的视觉呈现

## 参考作品分析

### 《雾锁山门》（归藏演示游戏）
- ✅ 完整的战斗系统（三段连招、闪避、格挡、弹反）
- ✅ 单HTML文件打包，约33MB
- ✅ 5个骨骼角色 + 12种场景道具
- ✅ 配音和音效完整

### 借鉴要点
- 战斗节奏：蓄力 → 爆发 → 衰减
- 手感核心：攻击自动归位、分级击退、顿帧
- 敌人设计："少而耐打"原则（3-4个敌人，每个4-5击）
- 输入优先级：闪避 > 一切

## 游戏设计

### 核心玩法
**战斗系统：**
- 基础三段连招（轻攻击）
- 重攻击（蓄力技）
- 闪避（无敌帧，可取消大部分动作）
- 格挡/弹反系统
- 处决技（反击窗口）

**角色设定：**
主角：林黛玉（剑）
- 轻盈、快速的战斗风格
- 技能：落英神剑、潇湘剑法

### 第一版范围（MVP）

**场景：**
- 大观园中的怡红院广场
- 一个完整的战斗区域（约30x30米）
- 假山、回廊、花树等障碍物

**角色：**
- 可操作：林黛玉（主角）
- 敌人：3-4个"幻影"小怪（第一波）
- Boss：薛宝钗（幻境对决）

**战斗系统（完整实现）：**
1. 基础连招：轻攻击三段（挥剑 → 刺击 → 旋斩）
2. 重攻击：蓄力剑气斩
3. 闪避：翻滚（0.5秒无敌帧）
4. 格挡：剑挡（成功格挡进入弹反窗口）
5. 弹反处决：反击窗口内的高伤技能
6. 技能：落英神剑（范围AOE）

**不包含（后续版本）：**
- ❌ 多场景切换
- ❌ 剧情对话系统
- ❌ 装备升级
- ❌ 多角色切换

## 技术方案

### 技术栈
- **核心引擎：** Three.js r163+
- **物理/碰撞：** 自制胶囊体碰撞（不用物理引擎）
- **动画：** 程序化生成 + 预设动作库
- **打包：** Vite + 内联资源 → 单HTML文件
- **目标大小：** ≤ 40MB

## 手感检查点（战斗手感清单）

基于归藏skill的combat-feel.md，必须实现：

### 核心手感
- [ ] **攻击归位**：轻攻击在1-3米内自动调整朝向和滑步
- [ ] **顿帧**：击中敌人时目标顿帧0.1秒（不是全局慢动作）
- [ ] **身体碰撞**：普通状态下角色之间有碰撞，闪避时无碰撞
- [ ] **输入缓冲**：受击硬直期间的输入会在硬直结束时执行

### 玩家能动性
- [ ] **闪避优先级最高**：几乎可以取消任何动作
- [ ] **格挡/弹反窗口**：成功格挡后有明确的反击窗口提示
- [ ] **处决技**：反击窗口内的高伤害技能

### 敌人设计
- [ ] **少而耐打**：3-4个敌人，每个4-5击才死
- [ ] **单个近战**：同时只有1个近战敌人攻击玩家
- [ ] **包围圈**：其他敌人保持在周围形成压力

### 相机与空间
- [ ] **相机leash**：保持玩家在相机中心3-4米内
- [ ] **场景测试**：自动寻路测试覆盖全地图，无死角

## 关键技术难点

1. **角色朝向修正**
   - 生成的模型可能有90°偏转
   - 需要计算左右大腿骨骼算出朝向

2. **程序化攻击动画**
   - 不猜关节角度，用IK求解
   - 手部目标位置 + 剑方向 + 脚步位置

3. **攻击归位**
   - 检测前方锥形范围内的敌人
   - 插值旋转 + 滑动位移

4. **特效节奏**
   - 蓄力 → 爆发 → 衰减
   - 避免第一版过曝（bloom值控制在2-3）

5. **单文件打包**
   - Base64内联所有资源
   - Gzip压缩
   - 懒加载优化

## 验证里程碑

每个阶段必须在浏览器中验证：

1. **Phase 3后**：角色能在场景中移动，相机跟随正常
2. **Phase 4后**：按键能触发攻击动画，动作流畅
3. **Phase 5后**：能打中敌人，有击中反馈，敌人会反击
4. **Phase 6后**：有完整的视听反馈，战斗有节奏感
5. **Phase 7后**：单HTML文件可独立运行，≤40MB
