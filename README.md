# 红楼梦3D动作游戏 🎮

**Dream of the Red Chamber - 3D Action Game**

基于Three.js打造的红楼梦题材3D第三人称动作游戏，采用归藏游戏skill的专业开发流程。

## 🎯 游戏特色

- **中国古典文学 × 武侠动作** - 红楼梦的角色与场景，武侠风格的战斗系统
- **完整战斗系统** - 三段连招、闪避、格挡、弹反、处决技能
- **精致手感** - 攻击归位、击中顿帧、分级击退
- **大观园场景** - 怡红院广场，假山、回廊、花树等中国园林元素
- **单HTML文件** - 所有资源内联，可独立运行

## 🎮 操作说明

- **WASD** - 角色移动
- **鼠标移动** - 转向
- **鼠标左键** - 轻攻击（三段连招）
- **鼠标右键** - 重攻击（蓄力剑气）
- **Shift** - 闪避翻滚
- **Space** - 格挡
- **Q** - 必杀技：落英神剑
- **E** - 技能：剑气斩

## 🚀 快速开始

### 在线体验

访问 [GitHub Pages](https://你的用户名.github.io/hongloumeng-3d/) 在线游玩

### 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 🎮 角色设定

### 主角：林黛玉
- 武器：青锋剑
- 特点：轻盈灵动，速度快
- 技能：落英神剑、潇湘剑法

### Boss：薛宝钗
- 武器：宝扇
- 两个战斗阶段
- 特殊技能：金钗雨、旋风斩、飞行突袭

## 🏗️ 设计原则

基于归藏游戏skill的专业标准：

- **攻击归位** - 自动调整朝向和距离
- **顿帧反馈** - 击中时目标暂停0.1秒
- **闪避优先** - 可取消大部分动作
- **少而耐打** - 敌人数量少但有策略性
